# 검토한 일반 경제 뉴스

PR #14의 공식 발표와 수정판 작성 흐름에 편집자가 검토한 경제 기사를 추가한다. 수집기는 저장소의 선택 파일 `config/reviewed-economic-news.json`을 읽는다. 초기에는 이 파일 없이 기존 공식 발표로 운영한다. 이 Draft의 테스트 기사와 수치는 가상 자료다.

## 후보 입력

입력은 JSON 배열이다. 검토자는 원문을 열어 보도 시각, 보도의 근거, 공개할 사실 요약과 해석을 확인한다. 매체 기사 본문, 이미지, 검색 API 응답은 저장하지 않는다. 승인된 원문의 링크와 편집자가 작성한 요약을 쓴다.

| 필드 | 입력 |
|---|---|
| `source`, `sourceName` | 추적 매개변수를 뺀 기사 링크와 화면에 표시할 매체명. 현재 참고 사례의 두 매체 코드만 허용 |
| `publishedAt`, `observedAt` | 시간대가 있는 ISO 8601 보도 시각과 내용 기준 시각. 장중 시장 사례에는 둘 다 필수 |
| `region`, `priority` | 국내 경제에 직접 해당하면 `kr`, 해외 중심이면 `overseas`. 중요도·국내 관련성·학습 가치는 검토자가 1–3으로 평가 |
| `topic`, `eventId` | `global_sentiment`, `market_links`, `orders_exports` 중 하나와 동일 사건에 공통으로 사용하는 식별자 |
| `title`, `fact`, `interpretation`, `study`, `verified` | 편집 제목, 확인한 사실, 별도 시장 해석, 학습 포인트, 검토 완료 시 `true` |

국내 일반 기사를 우선 채택한다. 그다음 국내 관련성이 확인된 해외 기사와 기존 공식 발표로 남은 자리를 채운다. 같은 우선순위에서는 최신 보도를 먼저 읽는다. 선정 구간은 직전 리포트 기준 시각 초과부터 현재 마감 시각 이하까지다. 주말 보도도 구간에 들면 실제 보도 시각을 유지한다. 최초판과 수정판에는 동일 사건·링크를 반복하지 않고, 이미 공개한 카드는 보존한다. 편집자는 같은 사건의 언론 보도와 공식 발표를 함께 후보로 올리기 전에 중복 여부를 확인한다.

| 기사 유형 | 학습과 퀴즈 |
|---|---|
| 해외 증시·투자은행 전망 | 변동성과 위험 회피. 관측한 가격과 기관의 예측 구별 |
| 국내 장중 반도체·수급 | 국제 증시 연결. 보도·관측·확정 종가 시각 구별 |
| 국내 기업 해외 수주 | 인프라 수요와 매출 인식. 여러 분기 납품 계약에 적용 |

## 자동 수집을 추가하는 조건

매체가 허용하는 제공 방식, 원문 접근 여부, 발표 시각의 정확성 및 요약 공개 범위가 확인된 매체부터 연결한다. 현재 네이버 뉴스 링크는 이 환경에서 본문을 자동 조회하지 못했다. 또한 네이버 검색 API는 검색결과 제공 목적과 표시 방식에 조건을 둔다. [API 이용약관](https://developers.naver.com/products/intro/terms/terms.md)

파일 읽기 실패, 검증 실패, 중복, 구간 외, 후보 없음은 각각 수집 결과에 기록한다. 편집자가 원문 접근을 확인할 수 없으면 입력하지 않는다. 운영 자동 수집을 도입할 때는 출처별 원문 접근 실패도 기록한다.
