## 화면·자동 갱신에서 검증한 사항

- 실제 데이터 2회 × Chromium 320·360·390·768·1280px 검증 통과.
- 네 지수 모두 대시보드와 SECTION 01의 종가·등락률·기준일 일치, 출처 링크 정상.
- 대시보드를 열어둔 상태에서 데이터 파일을 다음 실응답으로 교체하고 브라우저 시계를 60초 진행했다.
  수동 새로고침 없이 수집 확인 시각과 네 지수 표시를 다시 읽는 것을 확인했다.
- 최신 리포트 바로가기도 60초마다 재확인하며, 앱으로 돌아와 화면이 보이면 즉시 다시 읽는다.
- 이 갱신은 발행된 JSON을 읽는다. 브라우저가 시장 API를 직접 호출하지 않는다.
- 날짜별 리포트는 해당 날짜의 기록을 유지하며, 생성 파이프라인이 새 스냅샷을 렌더링한다.
- 최신 링크·아카이브·4 SECTION·퀴즈, 기존 공개용 합성 화면 검증도 5개 너비 통과.
- 값 변경→단일 출처 대기→불일치 시 숫자 제거는 합성 자료 3회와 페이지를 새로 열지 않는 타이머 시험으로 확인했다.
- Python 23개 테스트 통과. 공개/비공개 분리, 단일 출처의 잘못된 교차 검증 표시 방지,
  만료/저장 불허 차단, 통신 재시도 제한, 세션/불일치/누락, 원본 보존·중복·경쟁 발행을 포함한다.

## 비공개 재실행

저장소 밖 개인 설정과 허용된 제공처 접근 범위를 그대로 사용한다.
공개 `config/market-sources.json`, 운영 변수, 워크플로 YAML은 수정하지 않는다.

```bash
python scripts/check_private_market.py --config /absolute/private/path/config.json --rounds 2 --allow-single-source
```

`--allow-single-source`를 생략하면 기존처럼 두 독립 출처가 일치한 지수만 표시한다.
개인 설정의 각 제공처에는 `enabled`, `collectionAllowed` 및 별도 `private`의
`display`, `derivedReturns`, `temporaryStorage`, HTTPS `evidence`,
`reviewedAt`, `validThrough`, 제공처 `copyrightNotice`를 사용한다.
이는 기존 비공개 시험 설정 구조이며 이번 작업에서 공개 권한 검토를 추가하지 않았다.

Python 의존성과 Node Playwright/Chromium이 필요하다.
브라우저가 기본 위치에 없으면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정한다.
공개 Actions에서는 실행을 거부한다. 127.0.0.1에만 제공하는 접근 제한 임시 사이트에서
시험하고 외부 브라우저 요청·가격/원문/키/예외 출력·스크린샷·트레이스를 막는다.
정상/오류 종료 시 임시 사이트를 제거한다. 최종 실행에서 정리를 확인했다.
