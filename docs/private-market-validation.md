## 공개 경로와 분리

`collect()`는 기존 공개 권한 검사 그대로 유지한다. `collect_private()`는 별도 비공개 권한을 검사한다.
두 경로는 동일한 거래일 계산·제공처 어댑터·종가/등락률 교차 검증을 사용한다.

비공개 결과는 `publication.status=private_only`이다. 공개 생성기는 이 결과를 거부한다.
권한이 없거나 만료되면 해당 제공처를 호출하지 않는다. 비공개 비교 출처도 별도 비공개 권한이 필요하다.
개별 제공처의 접근·임시 저장·계산·표시 범위 확인은 공개 재게시 검토와 구분한다.
설정의 true는 권한을 새로 만들어내지 않는다. 실제로 허용된 범위만 입력하고 제공처의 저작권 고지를 보존해야 한다.

`check_private_market.py`는 저장소 밖의 설정만 받고 공개 GitHub Actions에서는 실행을 거부한다.
접근 제한 임시 폴더에서 사이트 복사본을 만들고 `127.0.0.1` 임시 서버로만 브라우저에 제공한다.
브라우저의 외부 요청을 차단하고 가격·원문·키·예외 문자열·스크린샷·트레이스를 출력하지 않는다.
정상/오류 종료 시 임시 폴더를 정리한다. 마지막 실제 실행에서 정리를 확인했다.
Git 커밋, 업로드, Pages 배포, 공개 빌드 결과물 생성은 호출하지 않는다.

## 로컬 재실행

Python 의존성과 Playwright/Chromium이 설치된 비공개 개인 실행 환경에서 수행한다.
실행 중인 공개 워크플로나 저장소의 기본 `config/market-sources.json`은 변경하지 않는다.

1. 저장소 밖 권한 제한 디렉터리에 기본 설정을 복사한다. 파일 권한은 소유자만 읽기/쓰기로 지정한다.
2. 허용된 제공처에 한해 `enabled`, `collectionAllowed`를 설정한다. `public` 값은 모두 그대로 둔다.
3. 해당 제공처에 다음 `private` 객체를 추가한다. 아래 false는 실제 허용 근거 확인 후에만 바꾼다.

```json
{
  "display": false,
  "derivedReturns": false,
  "temporaryStorage": false,
  "evidence": "",
  "reviewedAt": "",
  "validThrough": "",
  "copyrightNotice": "제공처와 원자료 권리자의 고지를 원문대로 보존"
}
```

`evidence`는 해당 비공개 이용 범위를 뒷받침하는 HTTPS 근거, 날짜는 ISO 형식이다.
네이버 등의 공개 웹 응답 수신만으로 주기적 수집 허가를 추정해서는 안 된다.
FRED 개인 비상업적 이용 안내도 원자료 권리자 조건과 고지를 함께 확인한다.
이번 개인 시험 결과는 장기 무인 수집이나 공개 사용 허가의 증거가 아니다.

```bash
python scripts/check_private_market.py --config /absolute/private/path/config.json --rounds 2
```

브라우저 실행 파일이 기본 위치에 없으면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정한다.
출력은 지수 ID·기준일·상태·화면 검사 결과만 포함한다.
화면 시험이 성공해도 네 지수 중 하나라도 교차 검증에 실패하면 종료 코드 1이다.
KRX/FSC를 별도로 허용받아 시험할 때만 `KRX_API_KEY`/`FSC_API_KEY`를 로컬 환경 변수로 제공한다.
현재 두 인증 제공처의 키를 이용한 검증은 미완료다.
