# 공식 발표를 학습 수정판으로 보완하는 설계

이 Draft는 콘텐츠 변경 명세다. 최초 발행은 국내 종가 조건에 따른다. 뉴스 수집은 기존 13초 제한을 사용하고 확인한 발표가 없을 때는 기존 학습과 퀴즈를 제공한다.

| 상황 | 원고 처리 |
| --- | --- |
| 17:07 최초판 | 직전 거래 리포트의 마지막 검토 마감 초과부터 17:07 이하의 Fed FOMC·BLS CPI·고용 발표만 선정한다. 지연 실행도 예약 슬롯을 따른다. |
| 같은 날 후속 슬롯 | 최초판의 선정 기간은 고정한다. 18:00·18:15·18:30까지 원문을 재검토하고 18:47에는 18:30 상한을 적용한다. 최초판이 늦게 생성된 경우에도 최초 마감 이후만 확장한다. |
| 오류 후 재시도 | 오류 난 출처의 미확인 구간은 같은 구간부터 다시 조회한다. 성공적으로 조회한 후보 없음, 원문 중복, 기간 밖, 잘못된 자료, 제공처 오류, 시간 초과를 구분한다. 오류를 성공한 검토로 기록하지 않는다. |
| 후보 선정 | 실제 발표 시각과 KST 변환값, 공식 원문 URL, 확인된 사실, 조건부 해석을 구분한다. 원문 식별자 및 주제·발표 회차로 중복을 막고 하루 합계 두 건까지 반영한다. |
| 다음 거래일 | 18:30 이후 발표를 다음 거래일 후보로 넘긴다. 주말·휴장을 포함하고 직전 마감 경계의 발표는 한 번만 반영한다. |
| 학습 연결 | FOMC는 정책금리, CPI는 물가와 구매력, 고용은 고용지표 해석 중 하나를 선정한다. 공식 발표에서 확인한 사실 하나를 사례로 쓰고 개념·출처·퀴즈·정답 해설을 연결한다. 새 학습은 기존 학습 뒤에 추가하며 이미 제공한 문제와 정답을 보존한다. |
| 뉴스 없는 날 | 복리·분산·지수·저축과 투자의 기존 설명과 퀴즈를 제공한다. 후보 없음과 수집 실패는 각각 다른 상태로 남긴다. |

최초판의 firstPublishedAt과 선정 마감, 출처별 검토 범위, 실제 발표 시각, 수정판의 추가 시각을 구분한다. 이후 원고 검증기는 최초판의 마감과 수정판의 별도 마감을 검증한다. 다음 거래일을 이미 발행한 뒤 복구할 때는 양일의 원문 식별자를 확인한다. 지연되어 실제 반영하지 못한 자료를 확인 완료로 기록하지 않는다.

최소 구현 순서는 section02_news.py의 수집 결과와 중복 판정, build_public_reports.py의 수정판 검증 및 학습 렌더링, refresh_public_market.py의 후속 슬롯 연결이다. 기존 데이터를 읽을 때 새 필드는 선택 사항이다. 최신 수정판을 복사해 변경된 항목만 더하고 지수·뉴스·학습·퀴즈를 보존한다. 동시 push 충돌 시 최신 main을 다시 읽는 기존 경로를 사용한다. 변경된 콘텐츠가 없으면 판을 추가하지 않는다.

합성 검증 사례는 17:07 최초판→18:20 발표 반영, 정각 경계와 18:31 다음 거래일 이월, 오류 후 재수집, 같은 원문의 반복 수신, 종가 수정과 콘텐츠 추가의 두 실행 순서, 기존 네 SECTION 및 퀴즈 보존이다. 과거 아카이브 재생성은 범위 밖이다.
