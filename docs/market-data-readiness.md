## 실제 테스트 결과와 한계

2026-10-26 22:16 KST 이후 이 실행 환경에서 확인:

- `KRX_API_KEY`, `FSC_API_KEY`: 환경 변수 미설정. GitHub Secrets의 존재 여부는 조회하지 못했으므로 GitHub에도 없다고 단정하지 않음.
- KRX 공식 페이지 직접 요청: 시간 초과.
- 금융위원회 API 무인증 접근 점검: HTTP 503. 인증 성공/데이터 수신 테스트가 아님.
- FRED CSV 최초 직접 요청은 시간 초과였으나 22:19 KST 진단 재시도에서는 NASDAQCOM의 10월 23일/22일 실제 응답을 파싱하여 거래일·종가·계산 등락률 단일 출처 검증 통과. SP500은 필요한 거래일 누락. 두 지수의 교차 검증은 미완료이고 가격은 공개 출력/저장하지 않음.
- 현재 시각 요청이나 과거 날짜 재조회로 ‘18시에 제공됐다’고 판정하지 않음. 승인된 환경에서 18:00·18:15·18:30에 실제 수신 시각과 기대 거래일을 기록해야 함.
- Python 자동 검증 17개 및 Chromium 320/360/390/768/1280px의 가격 표시/링크/수정판/오류 안내와 기존 11개 날짜/4 SECTION/퀴즈/검색/가로 넘침 검증 통과. 화면 테스트는 합성 수치로 수행.
- KRX 어댑터는 명세 기반 구현/합성 응답 검증 단계. 승인된 키로 운영 호스트/권한/실제 응답 형식을 재확인해야 함.

## 설정과 실행 순서

1. 국내 공급 경로부터 확인합니다. KRX OPEN API 로그인 → 인증키 신청(관리자 승인) → KOSPI 시리즈/ KOSDAQ 시리즈 각각 활용 신청·승인. 단, 공개 서비스에는 별도 제3자 표시/보관 허가 확인이 필요합니다.
2. 금융위원회를 비교 용도로 사용할 경우 공공데이터포털의 지수시세정보 V2 활용 신청 후 일반 인증키(Decoding)를 사용합니다. 코드가 쿼리 인코딩하므로 이중 인코딩하지 않습니다. 당일 제공 지연 한계는 남습니다.
3. GitHub 저장소 Settings → Secrets and variables → Actions → Secrets → New repository secret. 각각 `KRX_API_KEY`, `FSC_API_KEY`. 키를 채팅·커밋·원고에 넣지 않습니다. YAML은 발행 단계에만 주입합니다. 추가 기본 쓰기 권한 변경은 필요 없습니다.
4. 수집 테스트 허가를 확인한 제공자만 로컬 설정 사본에서 `enabled`, `collectionAllowed`를 켭니다. 공개 권한 플래그는 아직 켜지 않습니다. 사본은 저장소 밖에 둡니다.

```sh
pip install -r requirements-public.txt
# 승인된 키는 로컬 비밀 환경 변수로 주입. 명령줄 인자로 넣지 않습니다.
python scripts/check_market_connection.py --config /absolute/private/path/market-sources.json
```

도구는 실제 현재 시각의 기대 거래일, 제공처별 성공/실패, 교차 검증 결과만 출력합니다. 가격·수익률·원문·예외 문자열을 출력하거나 리포트를 만들지 않습니다. 모든 지수 비교 성공 전에는 종료 코드 1을 반환합니다. 한국 우선 단계에서는 한국 지수 결과를 먼저 판독하고 미국 ‘unavailable’는 미완료로 남깁니다.

5. 18:00·18:15·18:30 KST에 위 도구를 승인된 로컬/비공개 환경에서 실행하여 실제 가용성을 확인합니다. 수치 대신 수신 시각/기대 거래일/성공 상태를 기록합니다. 새 공개 워크플로를 만들지 않습니다.
6. 권한 확인 범위: 공개 Pages HTML 표시, 공개 JSON 제공, 공개 저장소 커밋과 이전 버전의 영구 보관, 다운로드/재배포, 전일 대비 계산, 출처 문구, 계약 만료 이후 과거 기록 유지. 단순 ‘웹 표시’ 승인만으로 공개 Git 기록까지 허용됐다고 처리하지 않습니다.
7. 범위가 확인된 1차 출처만 공개 설정의 `display`, `redistribution`, `derivedReturns`, `instruments`, `evidence`, `reviewedAt`, `validThrough`를 채워 활성화합니다. 비교 경로에도 수집 허용 필요. 가격 데이터는 키 설정만으로 공개되지 않습니다.
8. 사용자 검토 후에만 PR 병합. 병합 후 기존 Public Daily Study at 18 KST → Run workflow → main으로 수동 발행하고 publish/deploy 성공 및 실제 페이지를 확인합니다. 현 검토에서는 실행하지 않습니다.
