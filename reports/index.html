개인 리포트 연결

상세 리포트는 비공개 저장소에 보관됩니다. GitHub 로그인과 별도로 읽기 전용 토큰을 연결하면 이 탭에서 날짜별로 바로 읽을 수 있습니다.

연결 전에는 실제 수치와 리포트 목록을 불러오지 않습니다.

처음 연결하기

GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 RayGareth/market-reports-private 저장소만 선택하고 Contents: Read-only로 발급하세요. 만료일을 지정하고 토큰은 이 입력란에만 넣어 주세요.

토큰·리포트는 브라우저 저장소, URL, 공개 파일에 저장하지 않습니다. 새로고침하거나 탭을 닫으면 다시 연결해야 합니다.
