# Market Daily 🌿

경제·금융시장 공부와 날짜별 기록을 위한 개인 프로젝트입니다. 기존 Ivory & Sage 모바일 대시보드와 GitHub Pages 주소를 유지합니다.

- [홈 대시보드](https://raygareth.github.io/market-reports/)
- [날짜별 리포트 아카이브](https://raygareth.github.io/market-reports/reports/)
- [최신 리포트](https://raygareth.github.io/market-reports/reports/latest.html)

## 현재 개발 상태

- **PR #1**: 네 SECTION, 날짜별 아카이브, 최신 리포트 링크 — 병합 완료
- **PR #2**: 국내외 종가 수집·교차 검증 및 모바일 카드 — 병합 완료
- **PR #3**: 자료 미연결 안내 및 SECTION 01 가독성 — 병합 완료
- **PR #4**: 국내·미국 자동 갱신 분리, 마감 시각 표시, 날짜별 수정판 — **Draft, 운영 배포 전**

PR #4의 기술 구현과 합성 테스트가 통과했다고 해서 운영 홈페이지의 실제 숫자 갱신이 확인된 것은 아닙니다. 지금은 최신 main 반영, 실제 제공처 응답, 예약 실행, Pages 표시를 순서대로 확인하는 단계입니다.

## 네 지수의 표시

| 국내 | 미국 |
| --- | --- |
| KOSPI | S&P 500 |
| KOSDAQ | NASDAQ Composite |

- **확정 종가**: 지수 카드에서 가장 큰 글씨
- **마감 일시**: 종가 아래 작은 글씨, 한국 시간 KST
- **전 거래일 대비**: `+1.23%` 또는 `−0.85%` 형식
- **출처·검증 정보**: 원문 링크, 기준 거래일(미국은 ET), 마감 일시, 검증 완료 시각
- 실시간 시세가 아닌 **확정 종가**만 사용합니다. 날짜가 어긋나거나 수치가 일치하지 않으면 최신값을 추정하지 않고 이전 기준일을 정확히 표기합니다.

## 수집·교차 검증 구조 (PR #4)

- 국내 KOSPI/KOSDAQ: Yahoo Finance ↔ 네이버 금융
- 미국 S&P 500/NASDAQ Composite: Yahoo Finance ↔ FRED
- 같은 거래일 및 직전 거래일 종가를 두 출처에서 확인하며 수치·등락률을 교차 검증합니다.
- `config/market-sources.json`은 수집할 출처의 켜짐/꺼짐 상태를 관리합니다.
- `scripts/market_close.py`는 거래일·마감 시각·수치·변동률 검증을 수행합니다.
- `scripts/refresh_public_market.py`는 지역별 최신 대시보드 데이터와 날짜별 리포트를 연동합니다.
- `assets/market.js`는 검증 완료된 행만 카드에 표시합니다.
- 비밀정보는 브라우저·공개 JSON·로그에 포함하지 않습니다.

## 한국 시간 자동 갱신 (PR #4)

| 시장 | 대상 요일(KST) | 실행 시각(KST) |
| --- | --- | --- |
| 국내 | 월~금 | 18:00, 18:15, 18:30 |
| 미국 | 화~토 | 08:00, 14:00, 18:00 |

미국장은 미국 현지 거래일을 기준으로 계산하고 KST 날짜로 마감 시각을 표시합니다. 휴장·조기 폐장·서머타임, 중복 실행 및 늦은 데이터 도착을 처리합니다. 미국 갱신은 매일 리포트의 원고를 새로 생성하지 않습니다.

## 날짜별 네 SECTION

1. **SECTION 01 오늘의 시장 한눈에 보기** — 국내·미국 확정 종가, 등락률, 거래일, 출처
2. **SECTION 02 주요 이슈와 시장 흐름** — 확인된 사실과 학습용 해석
3. **SECTION 03 경제 공부** — 하루 한 가지 개념
4. **SECTION 04 복습 퀴즈** — 선택·정답 확인·해설·재시도

처음 발행한 HTML·원고는 보존합니다. 한국 종가가 늦게 확인되거나 다음 날 미국 종가가 확인되면 해당 **시장 거래일의 리포트**에 `-r001` 같은 수정판을 추가합니다. 같은 확정 종가를 반복 확인해도 중복 수정판을 만들지 않고 아카이브 링크를 최신 수정판으로 유지합니다.

기존 비공개 상세 보고서 저장소는 기록 보존용이며 자동 발행은 수동 실행 전용으로 전환되었습니다.

## 자동 검증 및 배포

```sh
pip install -r requirements-public.txt
python -m unittest discover -s tests -p 'test_*.py'
# Playwright가 설치된 환경:
node tests/public-reader.cjs
node tests/market-ui.cjs
node tests/readability-ui.cjs
```

PR #4의 마지막 코드 검증은 Python **39개**와 화면 폭 **320·360·390·768·1280px**를 통과했습니다. 이 기록은 합성 데이터 기반 테스트이며, 실제 API 응답과 Pages 배포 결과는 구분하여 확인합니다.

병합은 최신 `main`과 동기화하고 GitHub Actions 검증을 재실행한 다음 진행합니다. 강제 push나 아카이브 삭제를 사용하지 않습니다.
